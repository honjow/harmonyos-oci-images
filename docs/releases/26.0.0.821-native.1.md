# HarmonyOS API 26 Image with Native Build Tools: 26.0.0.821-native.1

Published on 2026-11-20 for `linux/amd64`. The variant extends the published
[26.0.0.821 image](26.0.0.821.md), reusing its DevEco command-line tools, SDK,
ohpm, Hvigor, Node.js, and Java. The SDK archive was not rebuilt or repackaged.

## Koma acceptance

[Koma's candidate image build](https://github.com/honjow/Koma/actions/runs/44710745672)
passed in 5 minutes 20 seconds at commit `0ec5ba95`. It pulled the exact image
digest, skipped APT, restored the existing native library cache, and produced
an unsigned Release HAP for Koma 1.5.6 (25) with Reader Kit `212fea38`.

Koma enables the verified digest through the `KOMA_OHOS_BUILD_IMAGE`
repository variable. Clearing it restores the original image and APT step.

[An ordinary build using the default repository configuration](https://github.com/honjow/Koma/actions/runs/44711628840)
passed in 3 minutes 57 seconds on the same commit after the switch. It pulled
the same digest, skipped the legacy install, restored the native library
cache, and produced a verified unsigned Release HAP. The previous
[1.5.6 main branch build](https://github.com/honjow/Koma/actions/runs/44702401407)
took 27 minutes 49 seconds. These are observed CI runs; pull and runner times
vary. The already published Koma v1.5.6 tag was not rebuilt.
