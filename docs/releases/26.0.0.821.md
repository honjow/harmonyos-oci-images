## macOS migration finding

The official Linux archive contains filenames that differ only by letter case,
including both of these paths:

```text
sdk/default/openharmony/native/sysroot/usr/include/linux/netfilter_ipv6/ip6t_HL.h
sdk/default/openharmony/native/sysroot/usr/include/linux/netfilter_ipv6/ip6t_hl.h
```

Direct extraction onto the default case-insensitive macOS filesystem caused an
overwrite prompt and failed. The permanent release flow therefore extracts in
Linux, sends the compressed tar archive to the Docker build context, and only
extracts it in a Linux build stage. The Dockerfile asserts that both header
paths survive.
